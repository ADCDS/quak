# Quak 会更改和存储什么，又能删除什么

Quak 控制的是一台真实的相机，并且可以操作您电脑的 Wi-Fi。本页将准确说明它会做什么。

## 在您的电脑上

**Bluetooth**：Quak 通过系统的 Bluetooth 以常规方式与相机配对。它不会更改其他任何内容。

**Wi-Fi**：预览、媒体和下载需要使用相机自身的 Wi-Fi 网络。

- **手机**：Android 只为本应用建立连接，其他应用仍使用您平时的网络。
- **电脑**：一块 Wi-Fi 网卡会暂时加入相机的网络，并离开原来所在的网络，直到 Quak 使用完毕。

在电脑上，Quak 会：

- 优先使用您没有用来上网的网卡。如果唯一的网卡正是您在用的那块，应用会先询问您；命令行则会报错并停止，直到您用 `--wifi-adapter NAME` 选择它。
- 在 Linux 上，创建一个名为 `quak-camap` 的临时 NetworkManager 配置文件（它绝不会占用您的默认路由或 DNS），并在用完后将其删除。Quak 不会修改您的其他配置文件。
- 在 Linux 上，使用期间关闭该网卡的自动连接，否则已保存的相机配置文件可能会重新占用该网卡。之后会恢复自动连接。
- 完成后重新连接您之前的网络。应用会在您离开“媒体”或停止预览约一分钟后执行此操作。

### 如果 Quak 被强制结束

命令行程序在收到 Ctrl-C 和 `kill` 时会进行清理，并恢复它所做的更改。如果以更强硬的方式结束它，或电脑在使用中断电，Quak 会记住它所做的更改，并在 Linux 上下次启动时撤销这些更改。在 Windows 上，没有自动恢复功能。

要在 Linux 上手动恢复（其中 `DEVICE` 是您的 Wi-Fi 网卡）：

```bash
nmcli connection delete quak-camap
nmcli device set DEVICE autoconnect yes
nmcli device connect DEVICE
```

重启也会清除对自动连接的更改，之后只需删除 `quak-camap` 配置文件。

### 存储的内容

| 内容 | 位置 | 包含 |
|---|---|---|
| 已配对的相机、设置 | Linux 上为 `~/.config/quak`，Windows 上为 `%APPDATA%\quak`，Android 上为应用的私有存储 | 相机地址、型号、应用设置 |
| 下载内容 | 桌面应用为 `~/Videos/Quak`，Android 上为应用的私有存储，命令行为 `--out` 指定的位置或当前文件夹 | 您的片段 |
| 测试数据 | Linux 上为 `~/.local/state/quak`，Windows 上为 `%LOCALAPPDATA%\quak` | 仅在您运行测试套件时才有 |

Quak 不会存储您的 Wi-Fi 密码或推流密钥。在您要求相机加入网络或开始直播时，Quak 会把它们发送给相机。

### 日志中的内容

“诊断”界面、其导出的日志和 `quak -v` 会显示与相机交换的字节。其中不包含密码、推流密钥、网络名称、相机序列号和您电脑的名称，并会注明隐藏了多少字节。

相机的 Bluetooth 地址仍可能出现在错误消息和日志中，因此公开分享日志前请先检查。

### 应用的网络访问

`quak-gui --web` 在浏览器中提供应用，仅限本机访问。**没有登录机制**，任何能够访问它的人都可以用您的相机录制并删除其中的内容，因此 `--host` 只有在您完全信任的网络上才有意义。

## 在相机上

配对时，**Quak 会把您电脑的名称告诉相机**，作为相机显示的此设备名称。

**定时拍摄会更改设置，并且不会改回去**。设定定时拍摄时会：

- 将相机切换到专业控制，因为相机在简易控制下会隐藏定时拍摄
- 加载您选择的视频预设
- 设置视频时长，这**也会限制您手动开始的录制**
- 同步相机的时钟

设定时如果更改了这些内容，Quak 会告诉您。完成后，请在相机设置或 Quak 中把时长改回来。

**直播**：

- 相机会加入您选择的 Wi-Fi 网络并将其保存。只有相机上的**重置连接（Reset Connections）** 才能移除已保存的网络，而且这也会移除相机的所有配对。
- 您的网络密码和包含推流密钥的推流 URL 会通过 Bluetooth 发送给相机。
- 如果使用普通的 `rtmp://` URL，推流密钥和视频会以未加密的方式传输到服务器。

**相机 Wi-Fi** 会在需要时开启；如果是 Quak 开启的，Quak 用完后会将其关闭。预览期间被强制结束的应用可能会让它保持开启：请运行 `quak ap off`，或在相机上将其关闭。

## Quak 可以删除什么

只能删除您选择的片段。在应用中删除片段时总是会要求确认，在命令行中则需要 `--yes`。已删除的片段无法恢复。

Quak 无法格式化存储卡、删除全部内容或将相机恢复出厂设置。

下载绝不会覆盖现有文件：第二个 `GX010001.MP4` 会保存为 `GX010001_1.MP4`。中断的下载会报告为错误，不会被当作完整文件保存。

## 开发者须知

`QUAK_DEV=1` 会显示应用的自检和“直播”的测试模式。它们改动的内容要多得多，因此请先阅读 [testing.md](https://github.com/ADCDS/quak/blob/main/docs/testing.md)：

- **自检**：耗时约 30 分钟，会录制片段、更改设置并恢复，还会使用 Wi-Fi 网卡。
- **测试模式**：把这台电脑变成热点，相机会保存该网络。
