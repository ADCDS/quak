# Security

Quak handles Wi-Fi passwords and stream keys, can change a computer's network, and can delete clips from a camera. If you find a
way it could leak those or do something you didn't ask for, please report it privately rather than opening a public issue:
use **Report a vulnerability** on the repository's [Security tab](https://github.com/ADCDS/quak/security).

This is a small project, so replies may take a few days. Fixes go into the latest release.

[docs/safety.md](docs/safety.md) describes what Quak is meant to do.
