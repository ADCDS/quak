# Fonts

Bundled so the app looks the same on every platform. All three are under the SIL Open Font
License 1.1 (the `OFL-*.txt` files next to them); they come from github.com/google/fonts.

| File | Family | Used for |
|---|---|---|
| Inter.ttf | Inter (variable: opsz, wght) | body text |
| SpaceGrotesk.ttf | Space Grotesk (variable: wght) | headings |
| JetBrainsMono.ttf | JetBrains Mono (variable: wght) | bytes in the diagnostics log |
